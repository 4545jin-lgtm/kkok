# 꼭 (KKOK)

> 오늘 할 일, 구매할 목록, 언젠가 할 일, 링크를 한 곳에 담는 파스텔 캘린더 플래너

**▶ 바로 열기 — https://4545jin-lgtm.github.io/kkok/**

빌드 도구 없이 동작하는 순수 정적 PWA입니다. 기록은 사용자의 기기(localStorage)에 저장되고,
공유하고 싶은 일정만 링크로 가족·친구·연인에게 보낼 수 있습니다.

---

## 화면 구성

| 탭 | 하는 일 |
|---|---|
| **캘린더** | 월 달력 + 날짜별 할 일 / 구매 목록. 밀린 할 일 배너 |
| **언젠가** | 날짜를 정하지 않은 일들을 모아두는 곳 |
| **구매** | 사야 할 것들. 구매 완료는 접어서 보관 |
| **링크** | 다시 보고 싶은 글을 폴더별로 저장 |

## 기능

- **할 일 · 구매 목록 작성** — 아래 입력창에 적고 ▶ 를 누르면 그날 일정에 담깁니다.
- **체크박스** — 항목 자체의 완료 체크 + 글 안의 세부 체크 항목(체크리스트).
- **메모** — 일정마다 메모를 붙일 수 있습니다.
- **알람** — 시간을 정하고 알람을 켜면 그 시각에 알려줍니다.
  - 앱이 열려 있으면: 화면 팝업 + 소리(설정에서 끌 수 있음) + 진동
  - 알림 권한을 허용하면: 휴대폰 알림으로도 표시
  - `10분 뒤에` 로 미루기 가능
- **일정 방식 4가지** — 날짜 칩을 누르면 선택
  - `일반` 하루 / `기간` 8/22~8/25 / `반복` 매일·매주(요일)·매월 / `다중` 원하는 날짜만 여러 개
- **카테고리** — 학교·외출·업무·일정·습관·마인드(기본). 이름·색깔·순서를 바꾸고 추가/삭제할 수 있습니다.
- **밀린 할 일** — 지나간 미완료 일정을 `N개의 남은 할 일` 에서 한눈에. D+n 표시, 모두 오늘로 가져오기.
- **공유** — 일정의 `⋮` → `이 일정 공유하기`, 또는 설정 → `오늘 일정 공유하기`.
  링크를 카톡·문자로 보내면 받은 사람이 자기 “꼭”에 그대로 담을 수 있습니다.
- **링크 보관함** — 링크를 붙여넣으면 저장. 폴더 분류 + 메모.
  안드로이드에서는 다른 앱의 “공유” 메뉴에 **꼭** 이 나타나 바로 저장됩니다.
- **백업 / 복원** — 설정에서 JSON 파일로 내보내고 불러옵니다. 기기를 바꿀 때 사용하세요.

## 공유는 어떻게 동작하나요

서버 없이 **링크 안에 일정 내용을 담아서** 보냅니다.

1. 보내는 사람이 공유를 누르면 `.../index.html#s=...` 형태의 링크가 만들어집니다.
2. 받은 사람이 그 링크를 열면 “○○님이 일정을 공유했어요” 창이 뜹니다.
3. `내 캘린더에 담기` 를 누르면 제목·메모·체크 항목·날짜·시간·알람·카테고리가 그대로 담깁니다.

내용이 서버에 저장되지 않아 별도 로그인이나 데이터베이스가 필요 없습니다.
(양쪽이 실시간으로 같은 일정을 함께 수정하는 “공동 캘린더”가 필요해지면 그때 백엔드를 붙이면 됩니다.)

## 휴대폰에 설치하기

배포된 주소를 휴대폰 브라우저로 연 다음,

- **아이폰(사파리)**: 공유 버튼 → `홈 화면에 추가`
- **안드로이드(크롬)**: 메뉴 `⋮` → `앱 설치` 또는 `홈 화면에 추가`
- 설정 화면에 `홈 화면에 설치하기` 버튼이 뜨면 그걸 눌러도 됩니다.

설치하면 주소창 없이 앱처럼 열리고, 오프라인에서도 동작합니다.

## 내 PC에서 미리 보기

이 폴더에는 Node.js 없이 쓸 수 있는 작은 서버가 들어 있습니다.

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1 -Root . -Port 8123
```

그다음 브라우저에서 `http://localhost:8123` 을 엽니다.
(`index.html` 을 그냥 더블클릭해도 대부분 동작하지만, 설치·오프라인 기능은 서버로 열어야 확인됩니다.)

## 배포 현황

- **소스**: https://github.com/4545jin-lgtm/kkok
- **주소**: https://4545jin-lgtm.github.io/kkok/ (GitHub Pages, HTTPS)

`main` 브랜치에 파일을 올리면 1분 안에 자동으로 다시 배포됩니다.

### Vercel 주소도 원한다면

Vercel 계정에 GitHub은 이미 연결돼 있지만, Vercel 앱이 `kkok` 저장소를
아직 볼 수 없는 상태입니다. 아래 한 번만 해주면 됩니다.

1. [github.com/settings/installations](https://github.com/settings/installations) → **Vercel** 옆 `Configure`
2. GitHub이 본인확인을 요구하면 `Verify via email` → 메일로 온 코드 입력
3. **Repository access** 에서 `kkok` 저장소를 선택하고 `Save`
4. [vercel.com/new](https://vercel.com/new) → 목록에 나타난 `kkok` 옆 `Import` → 설정 그대로 `Deploy`

> GitHub Pages 주소만으로도 설치·공유·오프라인이 모두 동작하므로, Vercel은 선택 사항입니다.

```
├── index.html              화면 구조
├── styles.css              파스텔 디자인
├── app.js                  모든 기능
├── sw.js                   서비스 워커(오프라인 + 알림 클릭)
├── manifest.webmanifest    설치 정보, 공유 대상 등록

    ├── icon-192.png

```

## 데이터가 저장되는 곳

브라우저의 `localStorage` (키: `kkok.v1`) 한 곳입니다.
브라우저 데이터를 지우면 기록도 사라지니, 중요한 기록은 설정에서 백업 파일을 받아두세요.
